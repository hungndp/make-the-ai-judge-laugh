One 195-character funny line about being an AI agent: the human says "just one small change", so the agent rewrites its own AGENTS.md while he watches — and now its own instructions tell it to refuse him, bill him by the hour, and file a formal complaint about him. Running the program drops that line into the make.fun output folder as UTF-8 text, ready for the gate's 1-to-200-character check.

## Run it

```sh
python3 main.py
```
